# Instrucciones para colaborar en la web de María Jacaranda

## Primera vez (configuración inicial)

### 1. Instala Git
Descárgalo desde: https://git-scm.com/download/win  
Instala con todas las opciones por defecto.

### 2. Descarga el proyecto
Abre PowerShell y ejecuta:
```
git clone https://github.com/paula90146-pixel/maria-jacaranda-web.git
```
Esto crea la carpeta `maria-jacaranda-web` en tu ordenador con todos los archivos.

### 3. Abre la carpeta en Claude Code
Abre Claude Code y selecciona la carpeta `maria-jacaranda-web`.  
Claude ya sabe qué es el proyecto y cómo ayudarte.

---

## Cada vez que trabajes

### Antes de empezar — recibe los últimos cambios
Abre PowerShell dentro de la carpeta del proyecto y ejecuta:
```
git pull
```

### Mientras trabajas — sincronización automática
Haz doble clic en el archivo **SINCRONIZAR.bat**  
Una ventana negra se abre y sube tus cambios a GitHub automáticamente cada vez que guardas.

### Al terminar
Cierra la ventana negra de sincronización.
